# TECHFEST 2050: The Future Awaits

An immersive 3D interactive website built using Three.js and GSAP, designed to showcase futuristic technologies through dynamic animations, interactive objects, and engaging visual storytelling.

## 🚀 Project Overview

TECHFEST 2050 is a futuristic web experience that takes users on a journey through the technologies shaping the future. The website combines 3D graphics, smooth scroll animations, and modern UI design to create an engaging and interactive experience.

## ✨ Features

* Interactive 3D Earth
* Floating AI Cube
* Quantum Sphere Visualization
* Robotics Section
* Dynamic Camera Movement
* GSAP Scroll Animations
* Futuristic Glassmorphism UI
* Responsive Design
* Space-Themed Background
* Smooth Transitions

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Three.js
* GSAP
* ScrollTrigger
